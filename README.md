
## <img src="imagens/WaySafe (3).png" width="400"> WaySafe
A WaySafe é um projeto voltado para concessionárias que atuam nas rodovias do estado de São Paulo. Nosso objetivo é fornecer um sistema com dados consistentes sobre acidentes nas rodovias, permitindo que as concessionárias analisem as informações e tomem decisões estratégicas, seja para melhorar a infraestrutura ou implementar soluções que previnam tipos específicos de acidentes.
