## WaySafe
## 📋 Sobre o Projeto
A **WaySafe** é um sistema criado para concessionárias que atuam nas rodovias do Estado de São Paulo.  
Nosso objetivo é fornecer **dados consistentes** sobre acidentes rodoviários, permitindo análises estratégicas para **melhoria da infraestrutura** e **prevenção de acidentes**.

Com a WaySafe, as concessionárias podem identificar padrões, tomar decisões baseadas em dados e implementar ações que salvam vidas.

## ✨ Funcionalidades
- 📊 Dashboard interativa com estatísticas atualizadas de acidentes  
- 🛣️ Filtros por rodovia, período, tipo de acidente e gravidade  
- 🔎 Relatórios para suporte à tomada de decisão  
- ☁️ Armazenamento seguro dos dados  

## 🛠️ Tecnologias Utilizadas
- **Back-end:** MySQL, Docker  
- **Front-end:** HTML, CSS, JavaScript  
- **Gestão:** Trello, Git/GitHub
